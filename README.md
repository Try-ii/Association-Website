## 📌 About the Project

This project is the production website for the **Madinah Entrepreneurs Association (رياديون)**.

The previous website required a complete redesign and rebuild. The website was therefore rebuilt from scratch with a focus on:

- Modern and professional user experience
- Arabic-first RTL design
- Responsive layouts across devices
- Clear information architecture
- Accessibility and usability
- Easy navigation and content discovery
- Structured presentation of the association's programs, services, and resources

The current version is deployed online and serves as the association's public-facing website.

---

## ✨ Key Features
